MEMORY GROVE · PUBLIC-GOOD PROJECT

A place for stories.
Not for surveillance.

Last updated November 20, 2026

What we collect

The Memory Grove application code does not collect personal information on a server, create accounts, run analytics, show ads or send your family content to us. Stories, photographs, video, audio, transcripts and person records are encrypted with the passphrase you choose and saved locally in your browser’s IndexedDB. Encrypted drafts are saved locally as you work.

How encryption works

We use the browser's Web Crypto API, PBKDF2-HMAC-SHA-256 and AES-256-GCM. The passphrase is not saved. We cannot reset it or recover your memories if you lose it. A person with access to the device, the passphrase or a shared archive may be able to access its contents. A malicious or compromised version of website code could also be dangerous, so use a deployment you trust.

Photos, recordings and transcripts

Recording uses the camera and/or microphone only when you explicitly begin recording and grant permission. Original files are encrypted on this device. If you enable automatic downloads, an unencrypted copy may also be placed in your device’s Downloads. Local dictation is attempted only when the browser confirms on-device processing; Memory Grove does not silently fall back to cloud speech recognition.

Sharing and preservation

Encrypted .grove archives can be sent directly between relatives using a service you choose. We do not operate a family-sync server. Anyone with the archive and the passphrase can decrypt it; there is no remote revocation. Exported readable Markdown story books and optional original downloads are not encrypted. You control where they go.

What your browser and host can know

The hosting provider and your internet service may see ordinary requests for the app files and standard connection metadata, such as IP addresses. The hosting provider serves the same public app code to everyone; your local archive is not uploaded as part of normal app use. Browser vendors govern their own storage retention, permissions, and optional on-device AI models.

Storage is not a backup

Clearing browser data, browser eviction, device failure, or losing a passphrase may destroy access. Create encrypted archives frequently and store independent copies. Memory Grove's interface is append-only for committed stories, but it cannot prevent someone with control over storage or source code from tampering with or deleting their local copy.

Open-source, zero-cost intent

Memory Grove is a free, dependency-free public-good application. It does not require paid cloud infrastructure. You can inspect, self-host, modify and improve the code under the MIT License.
